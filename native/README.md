# SNOWD native app (iOS and Android)

A real native app built with Expo / React Native. It replaces the Capacitor web wrapper in `../mobile`.

## How it stays in sync with the website

- **Same backend.** It signs in to the same Firebase project, reads the same Firestore data and calls the website's API routes (`https://www.snowd.ca/api/...`) for jobs, payments and notifications.
- **Same business rules.** Pricing, order status, distances and types are imported straight from `../src/lib` (for example `@/lib/workOrders`). Change a rule there and both apps get it.
- **Separate screens.** The screens in `src/app` are native. A change to a web page doesn't change the app, and the reverse is also true.

## Layout

- `src/app` – screens (Expo Router). `(tabs)` is the bottom tab bar. `chat`, `job`, `operator` and `book` open on top of it.
- `src/components` – shared UI pieces.
- `src/lib` – Firebase, API calls, payments, photos and the theme.
- `ios/` and `android/` – generated by `npx expo prebuild`. Don't edit them by hand.

## Commands

```bash
npm install
npm run typecheck
npm run device -- --configuration Release   # build and install on a connected iPhone
npm run ios                                  # run in the iOS simulator
```

`.env` holds the public Firebase, Maps and Stripe keys, as `EXPO_PUBLIC_*` copies of the website's `.env.local`. Set `EXPO_PUBLIC_APPLE_PAY_MERCHANT_ID` to turn on Apple Pay after you create a Merchant ID in the Apple Developer portal.
